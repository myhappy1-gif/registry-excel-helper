# 등기 대조·입력 도우미

등기 PDF 수백 건을 엑셀과 **항목별로 대조·보완**하고, **직원이 승인한 줄만** 사내 프로그램에 입력(이번 단계는 모의 입력)하는 업무 자동화 앱입니다. 변상금(국유지 무단점유) 부과 기간까지 소유자별로 계산해 수정본 엑셀을 만들어 줍니다.

> **연습용 가짜(샘플) 데이터로만 동작합니다.** 실제 등기·사내 데이터, 개인정보는 이 저장소에 없습니다.
>
> **시연 주소**: https://my-app-one-theta-94.vercel.app
> 시연판은 가짜 데이터로 미리 읽어 둔 결과를 보여 주는 화면이며, 파일 저장·글자 읽기·AI 호출은 막혀 있고 이름·주민등록번호는 가려서 보여 줍니다.

## 이 앱이 해결하는 일

직원이 등기 약 300건을 하나씩 열어 엑셀과 눈으로 대조하고, 같은 내용을 사내 프로그램에 다시 손으로 입력하는 반복 작업은 오래 걸리고 오타·누락이 생기기 쉽습니다. 이 앱은 **읽기 → 대조 → 직원 확인 → 입력 → 리포트**를 한 화면 흐름으로 묶어, 사람은 **정말 판단이 필요한 항목만** 확인하게 합니다.

## 화면 흐름 (4단계)

1. **파일 불러오기** — 기존 엑셀, 구청 부과 이력 엑셀, 전화번호 엑셀, 등기 PDF를 읽습니다. 부과 종료일을 일괄 입력합니다.
2. **대조 결과** — 같음 / 자동 보완 / 충돌 / 확인 필요로 나누고, 충돌·확인 필요만 직원이 정합니다(같은 종류는 묶어서 처리, 원본 등기 바로 보기).
3. **승인** — 줄마다 사내 프로그램에 **입력될 값**과 바뀐 내용을 보고 승인·제외합니다.
4. **입력·리포트** — 승인한 줄만 입력하고, 막힌 줄은 건너뛰어 "미처리 목록"에 남깁니다. 수정본·전화번호 대조표·결과 리포트를 엑셀로 받습니다.

## 핵심 규칙

- 표기 차이(공백·쉼표·하이픈·날짜 모양)는 **같은 값**으로 봅니다.
- **엑셀 빈칸만** 등기 내용으로 자동 보완하고, 값이 다르면 수정하지 않고 **충돌 목록**으로 직원이 정합니다. (단, 소유기간은 등기가 기준이라 믿을 만할 때 등기 값으로 고치고 기록을 남깁니다.)
- 읽은 글자의 확신도가 90% 미만이면 자동 수정하지 않고 "확인 필요"로 보냅니다.
- **원본 엑셀은 절대 덮어쓰지 않고** 수정본을 새 파일로 만듭니다.
- **승인한 줄만** 입력하고, 입력 항목은 지번주소·성명·전화번호·주소·주민등록번호 다섯 개뿐입니다. 이미 입력한 줄은 다시 넣지 않고, 연속 5건 실패하면 멈춥니다.
- 부과 기간: 시작일은 구청 마지막 부과 종료일 다음 날(토·일이면 다음 월요일), 종료일은 일괄 입력한 날짜와 소유종료일 하루 전 중 이른 날. 소유자 교체·공유자·이력 없음은 각자 따로 계산합니다.

## 보안·개인정보

- 글자 읽기는 **이 컴퓨터 안에서만** 합니다(PDF는 `pdfjs-dist`로 글자를 그대로 꺼내고, 그림은 `Tesseract.js`). 외부 서버로 등기를 보내지 않습니다.
- 선택 기능 **"판독 강화"**(외부 AI로 한 번 더 읽기)는 기본이 꺼져 있고, 켜면 외부 전송 경고와 동의가 필요합니다. 지금은 가짜 샘플 파일만 보낼 수 있고 시연판에서는 항상 막힙니다.
- 비밀 값은 `.env`에만 두며 저장소에 올리지 않습니다(`.env.example`에 이름만 있음). 로그·리포트의 개인정보는 가려서 남깁니다.

## 실행 방법 (이 컴퓨터)

```bash
npm install
npm run sample        # 가짜 샘플 데이터 만들기 (엑셀·정답표)
npm run sample:phone  # 가짜 전화번호 엑셀
npm run dev           # http://127.0.0.1:3000
npm run test          # 규칙 시험
```

- 실제로 등기 PDF를 읽으려면 `OCR_MODE=local`로 실행합니다(Windows에서는 `앱 시작.bat` 더블클릭).
- 가짜 등기 PDF·그림은 `npm run sample:pdf`(Edge 사용)와 `scripts/make-register-images.ps1`로 다시 만들 수 있습니다.

## 만든 방식

- **기술 스택**: Next.js 16 (App Router) · React 19 · TypeScript(strict) · Tailwind CSS 4 · ExcelJS · pdfjs-dist · Tesseract.js · Vitest
- **구조**: 업무 규칙(대조·부과 기간·반복 검증·입력 큐)은 화면과 분리된 순수 함수(`lib/`)로 두고 단위 시험을 붙였습니다.
- **샘플**: 부과 사례를 일부러 설계한 가짜 등기 100건(소유자 교체·분할 부과·공유자·경계 사례 등)과 정답표로 측정합니다.
- **측정(가짜 PDF 100건)**: 항목 일치율 100%, 오류·빈칸 탐지 70/70, 직원이 볼 "확인 필요" 0.5%, 모의 입력 항목 일치율 100%. 실제 등기에서의 정확도는 별도로 시험이 필요합니다.
