# 재개발구역 변상금 부과 도우미

재개발로 용도폐지된 국유지의 **변상금 대상과 부과 기간**을 소유자별로 정하는 일을 줄여 주는 업무 자동화 앱입니다.
등기·구청 자료·엑셀을 **자동으로 대조**하고, 부과 기간을 계산한 뒤, **직원이 승인한 줄만** 입력합니다(이번 단계는 모의 입력).

> **연습용 가짜(샘플) 데이터로만 동작합니다.** 실제 등기·사내 데이터와 개인정보는 이 저장소에 없습니다.
>
> **시연 사이트**: https://my-app-one-theta-94.vercel.app
> 시연 사이트는 가짜 데이터로 미리 읽어 둔 결과를 보여 줍니다. 파일 저장·글자 읽기·외부 AI 호출은 막혀 있고, 이름·주민등록번호는 가려서 보여 줍니다.

## 어떤 일을 줄이나

재개발구역에서 국유지가 용도폐지되어 넘어오면, 그 땅 위 건물 소유자별로 점유 기간을 확인해 변상금을 부과해야 합니다.
대상이 수백 건이면 등기부·구청 부과 이력·기존 엑셀을 눈으로 맞춰 보고 대상과 기간을 정하는 일이 큰 수작업이 됩니다.
이 앱은 대조와 기간 계산을 먼저 해 두고, 직원은 **서로 다른 곳만** 확인해 승인합니다.

## 사용 순서

1. **파일 불러오기** — 기존 엑셀, 구청 부과 이력, 전화번호 엑셀, 등기 PDF를 읽습니다. 부과 종료일을 일괄 입력합니다.
2. **대조 결과** — 같음 / 자동 보완 / 충돌 / 확인 필요로 나눕니다. 충돌·확인 필요만 직원이 정합니다(같은 종류는 묶어서 처리, 원본 등기 바로 보기).
3. **승인** — 줄마다 입력될 값과 바뀐 내용을 보고 승인하거나 제외합니다.
4. **입력·저장** — 승인한 줄만 입력합니다. 수정본 엑셀, 전화번호 대조표, 결과 리포트를 내려받습니다.

## 주요 기능

- **등기 PDF 읽기** — PDF 안의 글자에서 소유자·주민등록번호·소유기간을 꺼냅니다(그림은 OCR).
- **엑셀 대조·보완** — 표기만 다른 값은 같은 값으로 보고, 엑셀 빈칸은 등기 내용으로 채웁니다.
- **다른 값은 직원이 선택** — 엑셀과 등기 값이 다르면 표로 나란히 보여 줍니다.
- **소유기간은 등기 기준** — 등기 값으로 고치고 바뀐 내용을 기록합니다.
- **전화번호 대조** — 등기에 없는 전화번호는 이름·주소로 전화번호 엑셀과 맞춥니다.
- **부과 기간 계산** — 소유자별 시작일·종료일. 시작일이 주말이면 다음 월요일입니다.
- **승인 후 입력(모의)** — 지번주소·성명·전화번호·주소·주민등록번호 다섯 항목만 입력합니다.
- **수정본 저장** — 원본 엑셀은 그대로 두고 새 파일로 만듭니다.

## 부과 기간 규칙

- 시작일 = 소유권이전일과 (구청 마지막 부과 종료일 + 1일) 중 늦은 날. 다음 날이 토·일이면 다음 월요일.
- 종료일 = 소유종료일 하루 전과 첫 화면에 일괄 입력한 날짜 중 이른 날(소유종료일이 비면 일괄 입력일, 입력이 없으면 오늘).
- 구청 부과 이력이 없으면 소유권이전일부터. 소유기간 전체가 구청 부과 종료일 이전이면 부과 대상이 아닙니다. 소유자 교체·공유자는 각자 따로 계산합니다.

## 안전장치

- 원본 엑셀은 수정하지 않습니다(수정본은 새 파일).
- 승인한 줄만 입력하고, 연속 5건 실패하면 멈춥니다. 이미 입력한 줄은 다시 넣지 않습니다.
- 읽은 값의 확신도가 90% 미만이면 자동 수정하지 않고 직원이 확인합니다.
- 등기는 **이 컴퓨터 안에서만** 읽습니다. 외부 AI("판독 강화")는 선택 기능이며 기본은 꺼져 있고, 켜면 외부 전송 경고와 동의가 필요합니다. 지금은 가짜 샘플 파일만 보낼 수 있고 시연 사이트에서는 항상 막힙니다.
- 바뀐 값은 출처와 함께 기록하고, 로그·리포트의 개인정보는 가립니다. 비밀 값은 `.env`에만 두며 저장소에 올리지 않습니다(`.env.example`에 이름만 있음).

## 샘플 측정 결과

가짜 등기 PDF 100건(소유자 교체·분할 부과·공유자·경계 사례를 일부러 설계)과 정답표로 쟀습니다.

| 항목 | 결과 |
|---|---|
| 오류·빈칸 탐지 | 70/70 |
| PDF 항목 일치율 | 100% (990/990) |
| 모의 입력 항목 일치율 | 100% (712/712) |
| 직원이 볼 "확인 필요" 비율 | 0.5% |

가짜 PDF는 깨끗한 글자라 **실제 등기에서의 정확도는 실제 자료로 따로 확인해야 합니다.**

## 실행 방법 (이 컴퓨터)

Windows에서는 `앱 시작.bat`을 더블클릭하면 서버가 켜지고 작업 화면이 열립니다. 직접 실행하려면:

```bash
npm install
npm run sample        # 가짜 샘플 데이터 만들기 (엑셀·정답표)
npm run sample:phone  # 가짜 전화번호 엑셀
npm run dev           # 소개 http://127.0.0.1:3000 / 작업 화면 http://127.0.0.1:3000/work
npm run test          # 규칙 시험
```

- 실제로 등기 PDF를 읽으려면 `OCR_MODE=local`로 실행합니다(`앱 시작.bat`이 이렇게 켭니다).
- 가짜 등기 PDF·그림은 `npm run sample:pdf`(Edge 사용)와 `scripts/make-register-images.ps1`로 다시 만들 수 있습니다.

## 만든 방식

- **스택**: Next.js 16 (App Router) · React 19 · TypeScript(strict) · Tailwind CSS 4 · ExcelJS · pdfjs-dist · Tesseract.js · Vitest
- **구조**: 업무 규칙(대조·부과 기간·반복 검증·입력 큐)은 화면과 분리된 순수 함수(`lib/`)로 두고 단위 시험 166개를 붙였습니다.
- **글꼴**: Pretendard(무료 오픈소스, OFL).
